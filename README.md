# 火力裂变：数字之门 V0.1

无需依赖、无需构建的 H5 竖屏射击游戏。直接打开 `index.html` 即可玩；手机上建议部署至 HTTPS 静态站点。

## 已实现
- Pointer Events 触控拖动与鼠标拖动，电脑方向键辅助
- 自动发射子弹，多弹道、伤害和射速升级
- 蓝色正向数字门与红色负向数字门，实际碰撞生效
- 普通敌人、重型敌人、追踪式场景移动、敌人碰撞和漏怪伤害
- 生命值、无敌时间、粒子反馈、得分、击杀统计
- 约 47 秒后生成 Boss，Boss 血量、攻击、胜利与失败结算
- 适配屏幕尺寸及高清 DPR，单 HTML 文件离线运行

## 测试
电脑双击 index.html 打开，点击开始战斗，拖动鼠标移动。手机可通过 GitHub Pages 等 HTTPS 静态托管访问。所有图形均由 Canvas 绘制，不需要外部素材。

## 注意
本版本为可玩原型，非完整商业美术版本。尚未实现音效、暂停、存档、武器库、关卡系统及多设备性能验证。
